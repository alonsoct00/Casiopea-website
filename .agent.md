# Agent Instructions for CASIOPEA Website

## 🤖 Contexto General del Proyecto

**CASIOPEA** es un sitio web estático para un estudio de animación en la Ciudad de México. Es un portafolio profesional que presenta proyectos de animación, motion graphics, stop motion y otras técnicas audiovisuales.

### Directoras
- Andrea Mondragón (@arena_mon)
- Sandra Medina (@sands_ml)

## 🎯 Objetivos Principales del Sitio

1. Mostrar portafolio profesional de proyectos de animación
2. Captar clientes y generar leads mediante formulario de contacto
3. Proporcionar información sobre el estudio (About Us)
4. Permitir filtrado y búsqueda de proyectos por categoría
5. Ofrecer experiencia visual atractiva y responsiva

## 🏗️ Arquitectura Técnica

### Stack Principal
```
Frontend:
- HTML5 (Estructura)
- CSS3 + Bootstrap 3 (Estilos responsivos)
- jQuery (Interactividad)
- Custom Plugins (Slider, Lightbox)

Backend (Minimal):
- PHP 5.6+ (Procesamiento de formularios)

Assets:
- SVG/GIF (Logos animados)
- PNG/JPG (Imágenes estáticas)
- MP4/MOV (Videos)
- JSON (Lottie animations)
```

### Componentes Personalizados
- `Header`: Navbar con logo y navegación filtrable (Web Component)
- `Footer`: Pie de página con información (Web Component)
- `Tera Slider`: Slider personalizado
- `Tera Lightbox`: Modal lightbox personalizado
- `Isotope Filter`: Filtrado de galería

## 🔧 Tareas Comunes para Agentes IA

### 1. Agregar Nuevo Proyecto
**Archivos a crear/modificar:**
- Crear: `projects/nuevo-proyecto.html`
- Crear: `projects/NombreProyecto/media/` (carpeta)
- Modificar: `proyectos.html` - agregar entrada a galería

**Estructura mínima:**
```html
<div class="project-item [CATEGORIA]">
    <a href="projects/nuevo-proyecto.html">
        <img src="projects/NombreProyecto/media/portada/preview.jpg" alt="Título">
        <h3>Título del Proyecto</h3>
    </a>
</div>
```

### 2. Modificar Contenido Existente
**Ubicaciones comunes:**
- Texto general → HTML de cada página
- Estilos → `stylesheets/the-casiopea-styles.css`
- Funcionalidad → `javascripts/functions.js`
- Información de contacto → En footer (Web Component)

### 3. Actualizar Videos Hero
- Desktop MP4: `videos/REEL_INICIO_V02.mp4`
- Desktop MOV: `videos/REEL_INICIO_V02.mov`
- Mobile MP4: `videos/REEL2026_WEB_VERTICAL_V03.mp4`
- Mobile MOV: `videos/REEL2026_WEB_VERTICAL_V03.mov`

### 4. Optimizar Rendimiento
- Minificar CSS → `stylesheets/style.min.css`
- Minificar JS → Verificar que haya versiones `.min.js`
- Optimizar imágenes → Usar herramientas como ImageOptim
- Lazy load de proyectos → Considerar implementar

### 5. SEO y Meta Tags
**Estructura presente:**
```html
<meta charset='utf-8'>
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta content='Description' name='description'>
<meta content='1 day' name='revisit-after'>
```

**Verificar en cada página:**
- `<title>` descriptivo
- Meta description
- Open Graph tags (si es necesario)

## 📱 Consideraciones de Diseño Responsivo

### Breakpoints Bootstrap
- `< 767px`: Mobile (columnas xs)
- `768px - 991px`: Tablet (columnas md)
- `> 992px`: Desktop (columnas lg)

### Patrón Responsive Común
```html
<picture>
    <source media="(max-width: 768px)" srcset="images/[mobile].jpg">
    <img src="images/[desktop].jpg" alt="">
</picture>
```

## 🚨 Errores Comunes a Evitar

1. **No actualizar enlaces relativos** al mover archivos
2. **Olvidar versión mobile** de videos en hero
3. **No minificar** antes de deploying
4. **Meta tags incompletos** en nuevas páginas
5. **Conflictos jQuery** - verificar versión compatibilidad
6. **PHP no configurado** - formulario contacto no funcionará
7. **Rutas absolutas** - siempre usar rutas relativas

## 📝 Convenciones de Código

### Nomenclatura
- Clases CSS: `kebab-case` (`.project-item`)
- IDs: `kebab-case` (id="main-home-page")
- Carpetas proyecto: `PascalCase` con guiones (NombreProyecto, Dos_Camaleones)
- Archivos: `kebab-case.html` o `lowercase.js`

### Estructura HTML
- Usar `container-fluid` y `row` de Bootstrap
- Secciones con `class="casiopea-section"`
- IDs para cada sección principal
- Web Components para header/footer (evitar duplicación)

### CSS
- Personalizar en `the-casiopea-styles.css` (no modificar Bootstrap)
- Mantener ordenamiento coherente
- Usar comentarios para grandes bloques

## 🔄 Flujo de Deployment

1. **Desarrollo local**: Probar en `localhost:8000`
2. **Testing**: Verificar responsivo en mobile/tablet
3. **QA**: 
   - Validar HTML
   - Probar formularios
   - Verificar videos cargan
   - Comprobar enlaces
4. **Deploy**:
   - Minificar CSS/JS
   - Subir a servidor
   - Verificar en dominio en vivo
5. **Monitoreo**:
   - Google Analytics
   - Monitoreo de emails de contacto
   - Log de errores 404
